# Rules CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Rules store out of the projects and give the agent one command that prints the active policy.

**Architecture:** A stdlib-only Python script in a standalone git repository. The store path comes from `RULES_DIR` or from the resolved script location. Projects keep one paragraph in `AGENTS.md` and no policy files.

**Tech Stack:** Python 3.13 standard library. `pytest` for tests (through `uv run --no-project --with pytest`). `textX` stays pinned inline in `validate.py`.

**Spec:** `docs/superpowers/specs/2026-11-17-rules-cli-design.md`

## Global Constraints

- Python 3.13, standard library only in `bin/rules`.
- `validate.py` keeps its PEP 723 header and the `textx==4.4.0` pin.
- One physical line per policy in `python.rules`.
- Never copy policy files into a project repository.
- No network dependency at `wake`.

## Review Focus

- A store directory without `.git` (fresh copy, tests): `wake` must still print the policy.
- A store work tree with edits: the version line must say `dirty`, not `clean`.
- A stale or broken remote: `wake` must not fail and must not hang past the timeout.
- A consumer that never installed the tool: stderr must say how to fix it.
- Policy text changes in the store must not require a project commit.

`tests/conftest.py`:

```python
import os
import shutil
import subprocess
from pathlib import Path

import pytest

ROOT = Path(__file__).resolve().parents[1]
CLI = ROOT / "bin" / "rules"


@pytest.fixture
def store(tmp_path: Path) -> Path:
    target = tmp_path / "rules-store"
    target.mkdir()
    for name in ("python.rules", "rules.tx", "semantics.md"):
        shutil.copy(ROOT / name, target / name)
    return target


def run(store: Path | None, *args: str) -> subprocess.CompletedProcess[str]:
    env = dict(os.environ)
    if store is not None:
        env["RULES_DIR"] = str(store)
    return subprocess.run(
        [str(CLI), *args],
        capture_output=True,
        text=True,
        env=env,
        check=False,
        timeout=60,
    )
```
